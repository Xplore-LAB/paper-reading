# paper-reading

论文精读与成果转化的标准流程（SOP）。

一套给 AI 助手用的 Skill，同时也可以当作人类自己读论文的模板。
目标是解决三件事：读论文读完就忘、想写解读文章时得从头再读一遍、做综述只会写"某某说…某某说"的流水账。

## 核心原则

> **一张卡片 = 一份笔记 = 一篇文章的草稿。**

读论文的产出不是"读完了"，而是一张结构化卡片。卡片填完，解读文章就完成 70%——
剩下的只是把行话换成口语、把条目换成段落。

## 三层流程：筛 → 拆 → 转

### 第一层 · 筛（Triage，10–15 分钟）

只读标题、摘要、引言、各级小标题、结论、图表（含 caption）和已读过的参考文献。
用 **5C 判断表** 给出结论：精读 / 略读 / 弃读，并写一句话理由。

| 维度 | 要回答的问题 |
|---|---|
| Category | 这是哪类论文？方法型 / 系统型 / 评测型 / 理论型 / 综述型？ |
| Context | 跟哪些工作相关？属于我课题的哪一类（基线 / 竞品 / 可借鉴 / 背景）？ |
| Correctness | 假设站得住吗？有没有明显硬伤？ |
| Contributions | 它到底新在哪？能一句话说清吗？ |
| Clarity | 写得清楚吗？图能看懂吗？ |

弃读是成功，不是失败。大多数论文只需要第一层。

### 第二层 · 拆（精读，30–90 分钟）

按 `templates/精读卡片模板.md` 填六段，每段有硬性规则：

| 段 | 名称 | 硬性规则 |
|---|---|---|
| 0 | 元信息 | 必须有论文链接 + 代码链接（没有就写"未开源"）+ 与我课题的关系 |
| 1 | 一句话导读 | ≤40 字，结构固定为 **痛点 + 方案 + 最亮数字** |
| 2 | 研究背景 | 必须举 **一个现实例子** 说明痛点，不许只写抽象描述 |
| 3 | 主要贡献 | ≤3 条，每条必须 **挂一个数字**（+21pp / 95% / 快 3×） |
| 4 | 研究方法 | 先给 **一条端到端主链路**（A → B → C），再分模块展开 |
| 5 | 实验结果 | 一块实验一小节，固定 **设定 → 指标 → 结论**，结论必须带数字 |
| 6 | 我的判断 ★ | 局限（作者承认的 + 我看出但没写的）、可信度、追问作者的 2 个问题、对我的用途 |

第 6 段是全套流程最值钱的部分，也是普通笔记和好笔记的分界线。

### 第三层 · 转（输出）

**模式 A：单篇 → 解读文章 / 公众号推文**（用 `templates/公众号解读稿模板.md`）
卡片段落与文章段落一一对应，只需三步：导读搬到开头做钩子、元信息压成表、
把条目式笔记改写成连贯段落，最后用"局限性 + 展望"收尾。

**模式 B：多篇 → 文献矩阵 / 综述**（用 `templates/文献矩阵.csv`）
一篇一行，按统一字段横向铺开。**矩阵的价值在于竖着读一列**——同列比下来，
谁的方法更强、谁的指标更好、哪里没人做过。空白格就是研究缺口，也就是你的机会。
综述严禁按作者流水账组织，必须按主题（列）组织。


## 使用方法

### 作为 AI Skill（WorkBuddy / Claude Code 等）

把整个目录复制到 skills 目录即可：

```bash
cp -r paper-reading ~/.workbuddy/skills/
```

之后直接说"按标准读一下这篇论文"或"把这张卡片转成文章"，助手会自动套用模板。

### 作为纯模板使用

不需要任何工具。读论文时复制 `templates/精读卡片模板.md`，
一篇一个文件，文件名建议 `卡片-论文简称.md`，统一放在一个目录下，
再用 `templates/文献矩阵.csv` 做索引，就是这个仓库的完全体。

## 方法论来源

这套标准综合了四个已验证的成熟框架：

- **Keshav 三遍法**：S. Keshav, *How to Read a Paper* (2007) — 三遍递进 + 5C 判断标准
- **李沐三遍法**：海选 / 精选 / 重点研读，强调读图表与脑中复现实验
- **剑桥 Paper Review Form**：Problem / Solution / Evaluation / 你的判断 / 追问作者的问题
- **文献矩阵 Synthesis Matrix**：Judith Garrard《Health Sciences Literature Reviews Made Easy》及各校写作中心

## 示例

`examples/示例-AquaWorld精读卡片.md` 是用一篇真实论文（AquaWorld，水下机器人仿真）
完整填写的示范。重点看第 6 段：里面拆出了论文自己没写的局限（样本量只有 20 次无置信区间、
基线偏弱、LLM 环节缺少消融），并明确标了"95% 这个数字不宜引用"——这才是精读的价值所在。
